# 1．教材名

川を横切るモーターボートのシミュレーション


# 2．教材の目的

高校物理の「速度の合成」を扱うシミュレーション教材とする。

川を横切るモーターボートを題材として、生徒が条件を変えながら次のことを観察できるようにする。

- 船首が向いている方向と、地面から見た実際の進行方向は一致しない場合がある
- 船の静水に対する速度と川の流れの速度を合成すると、地面に対する船の速度になる
- 正面に到達する条件と、最速で対岸に到達する条件は異なる
- 川の流速が船の静水中の速さを上回る場合、正面のゴールには到達できない

画面上に答えや考え方を説明する文章は置かない。
数式も表示しない。
生徒が操作、軌跡、ベクトル、結果から考えられる教材にする。

# 6．物理モデル

表示は川を真上から見た上面図とする。

座標を次のように定義する。

- x方向：川の流れに平行な方向
- 右向き：xの正方向
- y方向：対岸へ向かう方向
- スタート地点：x = 0、y = 0
- 対岸：y = W
- 川幅：W = 100 m

川の流速を vr とする。

川の速度：
(vr, 0)

ボートの静水に対する速さを vb とする。
ボートの向きを θ とする。

角度の定義：
- θ = 0°：対岸の正面を向く
- θ > 0°：上流側、画面左側を向く
- θ < 0°：下流側、画面右側を向く

ボートの静水に対する速度成分：

vx_boat = -vb × sin(θ)
vy_boat =  vb × cos(θ)

地面に対するボートの速度成分：

vx = vr - vb × sin(θ)
vy = vb × cos(θ)

位置更新：

x = x + vx × dt
y = y + vy × dt

yが川幅Wに達した時点で、対岸に到着したと判定する。

フレーム更新によってyがWを少し越えた場合は、直前の位置と現在位置の間を線形補間し、対岸に到達した正確な時刻とx座標を求めること。
フレームレートによって到着結果が変わらないようにする。

到着点のずれ：
- x > 0：下流側へのずれ
- x < 0：上流側へのずれ

正面到達判定：
- |x| ≦ 2.0 m：正面到達
- x > 2.0 m：下流側に到着
- x < -2.0 m：上流側に到着


# 7．時間とアニメーション

物理モデル上の時間と、画面上の実時間を区別する。

教材全体で固定の時間スケールを使用する。

固定値：

TIME_SCALE = 6.0

requestAnimationFrameで得た画面上の経過時間をrealDeltaTimeとしたとき、

simulationDeltaTime = realDeltaTime × TIME_SCALE

として、物理モデル上の時間と位置を進める。

重要：
- 課題、角度、流速、船速などの条件によってTIME_SCALEを変更しない
- 到着が遅い条件だけを自動的に高速化しない
- すべての条件で同じTIME_SCALEを使用する
- 横断時間として表示するのは、画面上の実時間ではなく物理モデル上の時間とする

課題1の次の条件では、画面上の実時間で約3秒で対岸に到着することを基準とする。

- 川幅：100 m
- 川の流速：2.0 m/s
- ボートの速さ：6.0 m/s
- ボートの向き：約19.5°上流側

この条件での物理モデル上の横断時間は約17.7秒である。
TIME_SCALE = 6.0の場合、画面上では約3秒で到着する。

極端に上流側または下流側を向け、対岸方向の速度成分が小さくなった場合は、到着まで長時間かかってもよい。
その場合も自動的に時間スケールを変更しない。
生徒は必要に応じてリセットできるようにする。

ブラウザのタブが非表示になった後などに、極端に大きな時間差が一度に適用されないよう、1フレームのrealDeltaTimeには適切な上限を設ける。


# 8．横断時間の表示

# 10．シミュレーション表示

川、岸、船は、すべて同じ上面視点で描く。

斜め上から見た立体的な風景と、真上から見た船を混在させない。
船の移動位置は、船体の中心を基準にする。

表示するもの：
- 上岸
- 下岸
- 川
- 水面上の右向きの流れ矢印
- ボート
- スタート表示
- 課題1・課題3のみゴール表示
- 課題1・課題3のみ正面方向の破線
- 必要に応じて軌跡
- 必要に応じて速度ベクトル

ボートは、船首方向と実際の進行方向の違いが分かるように描く。
船体は常に設定した船首方向を向き、実際の移動は合成速度に従う。

軌跡は、ボートの中心が通過した位置を線で結ぶ。
軌跡を船首から描かないこと。

課題1・課題3の船着き場は、対岸から川へ向かって1本だけ突き出す上面図の桟橋として描く。

## 速度ベクトル

速度ベクトル表示をONにした場合、ボートの中心を基準として次の3本を表示する。

- 船の速度（静水に対して）
- 川の流れの速度
- 船の速度（地面に対して）

3本は色を区別し、凡例を表示する。
ベクトルの長さは速さに比例させ、すべての課題で同じ表示倍率を使用する。

船の速度（静水に対して）は船首方向を向ける。
川の流れの速度は画面右向きとする。
船の速度（地面に対して）は、実際の移動方向と一致させる。


## 成分表示

成分表示をONにした場合、地面に対する速度ベクトルのx方向成分とy方向成分を、破線または細い矢印で表示する。

成分表示は、速度ベクトル表示がONのときだけ有効にする。
速度ベクトルがOFFの場合は、成分表示を自動的にOFFにしてよい。
