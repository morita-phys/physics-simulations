# 物理シミュレーション教材集

## 概要

このリポジトリは、高校物理の授業で使うシミュレーション教材をまとめるためのものです。

各教材は、ブラウザで直接開いて使える単一HTMLファイルとして作成します。生徒がまず現象を操作・観察し、そのあとで必要に応じて式や考え方を扱える教材を目指します。

## 公開方法

GitHub Pagesで公開する想定です。

公開後は、次のようなURLからトップページを開き、各教材へ移動できます。

```text
https://ユーザー名.github.io/リポジトリ名/
```

実際のURLは、GitHub Pagesの設定後に確認してください。

## フォルダ構成

```text
/
├─ index.html              # 教材一覧ページ
├─ README.md               # この説明ファイル
├─ AGENTS.md               # Codex向けの開発指示
├─ docs_chatGPT/           # ChatGPT用の設計方針・仕様書メモ
└─ simulations/            # 各シミュレーション教材
```

## 教材設計方針

この教材集では、現象先行・式後追い型の設計を基本にします。

- 生徒がまず操作・観察できることを重視する
- 数式や結論は原則として最初から表示しない
- 誤概念を助長しない図や表現にする
- Chromebookのブラウザで使いやすい画面にする
- 外部APIに依存しない

## 開発・更新の流れ

1. `simulations` フォルダに教材を追加する
2. `index.html` に教材リンクを追加する
3. ブラウザで表示確認する
4. GitHubにpushする
5. GitHub Pagesで公開状態を確認する

## 動作確認

- PCまたはChromebookのブラウザで開く
- 表示崩れがないか確認する
- 教材リンクが正しく開くか確認する
- 各教材のスライダー・ボタン・リセットが動くか確認する
- 開発者ツールのコンソールにエラーが出ていないか確認する

## 注意事項

- 生徒の個人情報を入れない
- 学校内部資料をそのまま置かない
- 公開前に物理的な誤りや表示崩れを確認する
- GitHub Pagesで公開される内容はインターネット上からアクセス可能になることを前提にする
