# 物理シミュレーション教材集

高校物理の授業で使用するシミュレーション教材を公開するためのリポジトリです。

## 公開ページ

https://morita-phys.github.io/physics-simulations/

## 内容

* `index.html`：教材一覧ページ
* `simulations/`：各シミュレーション教材

## 方針

各教材は、Chromebookなどのブラウザで開いて使用することを想定しています。

生徒が物理現象を操作・観察しながら理解できるようにすることを目的としています。

## 注意

このリポジトリには、公開用の教材ファイルのみを置きます。
開発用メモ、プロンプト、授業用資料、確認用画像などは含めません。
