数値計算の方法とモデルの意味

生徒用リファレンス

① 計算している運動方程式

円柱磁石の中心軸を原点とし、水平位置を (x, y)、中心からの距離を r = √(x²+y²) とします。磁力の大きさを f(r) とすると、力の向きは中心方向です。

Fx = −f(r) x/r,　Fy = −f(r) y/r（r = 0 のとき Fx = Fy = 0）

運動モデルは「並進のみ」m a = F と「転がり」(7/5)m a = F を選べます。転がりモデルでは一様な中実球が滑らず、磁気トルク・滑り・転がり抵抗がないと仮定しています。

② 選択できる磁力モデル（r：mm、力：N）

A 指数関数型（経験式）：f(r) = 0.1552048 r exp[−(r/9.23736)²]
B 分数関数型（経験式）：f(r) = 0.1247843 r / {1 + (r/8.91384)^4.67403}
C 理論磁場勾配：f(r) = 0.1667 r / {1 + (r/17.70)²}^4.65

経験式A・Bは測定した水平力の分布を近似するためのものです。理論磁場勾配モデルCは、一様に磁化された円柱磁石の理論B²分布の形を固定して、比例係数だけを実測磁力に合わせたものです。磁石の理論磁場と実測磁場の絶対値の差は未解決で、厳密な磁力理論ではありません。3つとも外側の距離での扱いには外挿が含まれます。

③ 数値解法：4次Runge–Kutta法（RK4）

位置・速度から加速度を計算し、微小時間 Δt ごとに更新します。オイラー法より計算精度が高く、1ステップ内で4回加速度を評価する仕組みです。標準 Δt=0.001 s、精度確認では0.0005 sにします。十分離れた位置まで到達したら散乱角を確定します。

④ 散乱角の定義（180°を超える場合も対応）

各時刻の速度ベクトルの向きから 連続する角度差（符号付き） を求め、足し合わせます。最後にその絶対値を取り、連続方向変化角（散乱角）とします。この値は180°を超えることがあります。単純な始速度と終速度のなす角（0〜180°）とは区別します。途中で十分遠くまで退出しなかった場合は、「未脱出」として散乱角を確定しません。

⑤ 入射位置 b と入射角 φ の関係

磁石半径は5 mmです。通常、左側 x₀ = −120 mm、y₀ = b+5 mm に球を置き、+x方向へ進ませます。入射方向 φ や横位置ずれ δb を設定すると、進入直線から磁石中心までの距離は変化します。実際の直線の最短距離も表示します。

⑥ 計算結果の保存・実測比較

軌道CSVには t, x, y, vx, vy, Fx, Fy, r と計算条件が入ります。一括計算CSVには b, v₀, 散乱角, 最接近距離, 判定と計算条件が入ります。グラフはPNGで保存できます。実測67件は斜面角度が記録されていない試行も含めたもので、Trackerの詳細な座標原点は確定していません。

⑦ 計算を検証するための確認

一つの条件を時間刻み0.001 sで計算し、次に0.0005 sで再計算してください。散乱角や最接近距離がどれほど変わるでしょうか。また、入射角や横位置を少しずらすと結果がどう変わるでしょうか。出た結果が実験と一致しなくても、原因をひとつに決めつけず、初期条件・力モデル・実験上の誤差を区別して考察してください。
